# 개조 계획: desca → PIX4D 전용 3D 편집 앱

- 날짜: 2026-10-29
- 요청 기록: `docs/intent/2026-10-29-desca-pix4d-3d-editor.md` (확정)
- 기준: `docs/analysis/2026-10-29-desca-features.md`, `docs/analysis/2026-10-29-pix4d-installers-rea.md`
- 원칙: 3D 가져오기만 PIX4D용으로, 나머지 전부 동일.

## P0. 그대로 빌드 (바탕 확인)
- Windows + MSVC2022 + Qt 6.8로 `desca/` 그대로 구성·빌드·실행.
- 있는 것: `cmake 4.4.2`, `ninja 1.13.2`, VS2022. 없는 것: Qt 6.8 (어디에도 없음, 확인).
- Qt 구하기가 첫 관문이다. 아래 질문에 답하면 바로 받는다.
- 확인: 앱이 켜지고 예제 3MX(또는 합성)가 열린다.

## P1. 점구름 읽기 (먼저)
- `core/`에 Qt 없는 LAS 1.2/1.4 읽기 추가 (PIX4D 점구름 `.las`, 나중에 `.laz`).
- 연 것: 점만 있는 모델도 열린다 (표시·단면은 P2).

## P2. 점구름 보기·단면
- 평면에 점 찍기, 단면 띠 안의 점 자르기·보기.
- 나머지는 메시 길과 같은 화면·목록·되돌리기.

## P3. 그물망 읽기
- PIX4D OBJ 내보내기는 desca OBJ 길로 먼저 시험 (될 수 있다).
- `.fbx`·`.osgb`·`.slpk`·`.p4b`는 시험 파일이 온 뒤 순서대로.

## P4. 프로젝트 열기
- `.p4d`(Mapper)·`.p4m`·`.opf`(Matic)에서 결과물 경로를 찾아 연다.

## 그대로 두는 것
- 리본·단면 목록·레벨선·도면·내보내기·명령줄·시험·빌드 방식.
- `desca` 원본 파일은 고치지 않고 복사본(`pix4d3d/`)에서 작업한다 (원본 보존).

## 확인 방법
1. `cmake` 구성·빌드·`ctest` 통과.
2. PIX4D 점구름 1개가 앱에서 열린다.
3. 단면·도면·내보내기가 예전과 같이 된다.

## 위험
- Qt 구하기가 오래 걸릴 수 있다 (아래 질문).
- 실제 PIX4D 파일이 없으면 P1 시험이 합성·예제로만 된다.
