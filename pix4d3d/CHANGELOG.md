# 바뀐 점 (CHANGELOG)

## 1.2.1 (2026-10-06)
1.2.0 이후 바뀐 점. 실제 Windows 신고(제주 3MX)와 「뒤로 3 m 는 보여야 입면도를 그린다」「잘린 면이 정확해야 한다」 요청 처리.

- **뒤 깊이(입면 배경) 기본 3 m**(1.2.0 은 0.5 m) — 0–5 m 조절, 칩 0.5 / 1 / 2 / 3 / 5 m = 숫자키 1–5, 깊이 음영 유지.
  1.2.0 이 저장한 옛 기본값 0.5(사용자 표시 `backUserSet` 없음)는 3 m 로 이관, 사용자가 고른 값은 유지(설정·모델별 상태·단면 목록 JSON).
  내보내기(PDF·DXF·PNG·TIFF)에도 3 m 입면 영상이 들어감. `asec-section --back` 기본도 3 m.
- **잘린 면은 미리보기에서도 최고 해상도(잎) LOD** — 끄는 동안 입면 배경만 거친 LOD, 단면선은 단면 평면 ±1 mm 띠의 잎을
  지오메트리만 읽어 자름(미리보기 = 최종, 차이 0 mm). 제주 38 m 단면: 1 cm 간격 잎 연직 피킹과 중앙 0.00 / p95 0.27 mm.
- **단면선은 그림 칸에서 맨 위** — 입면 배경·기준선·축척 막대·「최종 계산 중」 상자가 가리지 않음(화면·내보내기 모두).
  화면은 0.1 px 허용으로 점을 솎아 빠르게 그림(내보내기는 꼭짓점 전부).
- **단면 화면 세로 과장** X 키 / 정보 띠 「세로:가로」 단추 ×1·×2·×5·×10, 기복이 작으면 「×5 권장」 안내. 화면만 — 도면·내보내기는 1:1.
- **창 제목 중복 수정** — 「… — 발굴 단면뷰어 1.2.0 - 발굴 단면뷰어」처럼 두 번 보이던 것.
- **휴대용 zip 한글 이름** — 읽어보기.txt 등 이름에 UTF-8 플래그(0x800)를 켜서 Windows 탐색기에서 깨지지 않음(`packaging/mkzip.py`).
- **명령줄 `--front` 만 줄 때 뒤 깊이가 0.5 로 돌아가던 것 수정**(지금 값 유지).
- 시험·진단: `--cut-check`(단면선 정확도·맨 위 그리기 기록), `--vex N`, `--plan-cam X Y mpp`,
  회귀 시험 `tests/test_backdepth.cpp`, `tests/test_cutplace.cpp`.
