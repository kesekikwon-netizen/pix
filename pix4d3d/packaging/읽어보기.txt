발굴 단면뷰어 1.2.1
===================

iTwin Capture(ContextCapture) 등이 만든 3MX 실사 메시를 열어, 평면에서 단면선을 긋고
10 cm 레벨선이 있는 깨끗한 단면도를 바로 보고 내보내는 프로그램입니다.

■ 1.2.1 에서 바뀐 점
  - 뒤 깊이(입면 배경) 기본 0.5 m → 3 m(입면도를 그릴 수 있게). 0–5 m 로 바꿀 수 있음: 칩 0.5 / 1 / 2 / 3 / 5 m = 숫자키 1–5.
    1.2.0 의 기본값(0.5 m)으로 저장된 설정은 3 m 로 바뀌고, 직접 고른 값은 그대로 둡니다.
  - 빨간 단면선은 미리보기 때도 가장 상세한 메시로 자르고, 언제나 맨 위에 그립니다(입면 배경·축척 막대 등이 가리지 않음).
  - 단면 화면 세로 과장: X 키(또는 정보 띠 「세로:가로」 단추) ×1 / ×2 / ×5 / ×10 — 얕은 기복 보기용, 화면만.
    도면·내보내기는 언제나 1:1. 기복이 작으면 「×5 권장」 안내가 뜹니다.
  - 창 제목에 「발굴 단면뷰어」가 두 번 보이던 것 수정.
  - 휴대용 zip 의 한글 파일 이름(읽어보기.txt)이 Windows 탐색기에서 깨지지 않게 함.

■ 사용 순서 (1.2)
 1. 「열기」(Ctrl+O) → iTwin Capture 결과 폴더의 .3mx 선택 (또는 창에 끌어다 놓기). OBJ 도 열립니다.
    시작 화면의 「이어서 열기」 또는 Ctrl+Shift+O 로 마지막 모델을 마지막 단면선·두께·화면 그대로 다시 엽니다.
    3MX 는 대략 모양이 먼저 뜨고, 평면 왼쪽 아래 카드에 「디테일 불러오는 중 n / N」이 보이다 다 오면 사라집니다.
 2. 「단면선」(S) → 평면에서 시작점 A, 끝점 A′ 클릭. 그리는 동안 리본 아래 줄에 길이·방위가 보입니다.
    Shift = 동서·남북 고정, Enter = 좌표 직접 입력, Esc = 취소. 끝점·가운데 손잡이를 끌면 단면이 바로 바뀝니다.
    방향 반전 R, 평행 이동 [ ] (0.1 m) · { } (1 m), 새 단면 N(B–B′, C–C′ … 이름이 붙고 왼쪽 「단면 목록」에 쌓임).
 3. 뒤 깊이(입면 영상에 보일 배경 깊이, 0–5 m, 기본 3 m — 입면도용): 칩 0.5 / 1 / 2 / 3 / 5 m = 숫자키 1–5.
    「깊이 음영」을 켜면 멀리 있는 면일수록 옅게 그려 앞뒤가 구분됩니다(내보내기에도 적용).
    잘못 바꾸면 Ctrl+Z(되돌리기) / Ctrl+Y(다시) — 단면선·두께·표시·높이 기준.
 4. 「도면」(Ctrl+P): 용지(A4/A3, 가로/세로)와 축척(1:10/20/40/100/맞춤)을 고르면 실제 비율 미리보기가 나오고,
    한 장에 넘치면 「1:200 으로 줄이기 · A3 로 · N장으로 나눠 붙이기」를 추천합니다.
    표제란에 도면명·축척·보는 방향·날짜·수평 EPSG·높이 기준이 들어갑니다. 형식 PDF / DXF / PNG / TIFF.
    (인쇄는 저장한 PDF 를 열어서 하세요 — 프로그램 안 인쇄 단추는 없습니다.)
 5. 다른 내보내기(리본 「내보내기」)
    - 단면 DXF(Ctrl+D): 빨간 단면선(레이어 SECTION_PROFILE, 색 1), 레벨선 10 cm / 50 cm / 1 m(레이어별, 모두 기록),
      표고 라벨(50 cm 마다), 입면 영상(IMAGE + PNG). 그리기 순서: 레벨선 → 영상 → 단면선.
      2D 도면(X = A 기준 거리, Y = 절대 표고) 또는 3D 실좌표.
    - 단면 영상(Ctrl+E): PNG / TIFF / GeoTIFF. 픽셀 크기 = 0.0254 × 축척분모 ÷ DPI (예: 1/20, 300 dpi → 1.69 mm).
      작업·인쇄 축척(1/10–1/50)에서는 레벨선 10 cm · 표고 숫자 50 cm. 인쇄 선 간격이 0.5 mm 보다 좁아지면 솎습니다.
    - 평면 GeoTIFF, 점군 XYZ / LAS, 단면선 CSV, 단면 목록(.sections.json — 파일 › 단면 목록 내보내기/가져오기).
    높이는 3MX 좌표계 값을 그대로 씁니다(변환 없음).

■ 조작
  View 1: 왼쪽 끌기 = 이동, 오른쪽 끌기 = 회전, 휠 = 확대/축소, F = 맞춤, T = 위에서
  View 2: 끌기 = 이동, 휠 = 확대/축소, 두 번 클릭 = 맞춤
  휠 확대/축소는 두 보기 모두 마우스 커서 아래 지점을 중심으로 부드럽게 움직입니다(터치패드 두 손가락도 됨).
  단면 화면의 레벨선: 기본 10 cm 선 · 50 cm 숫자. 선 사이가 화면에서 4 px 보다 좁아지면 50 cm·1 m 로,
  숫자가 겹치면 1 m·5 m 로 솎습니다(10 cm 보다 촘촘하게는 그리지 않음). 단면 제목에 현재 간격이 표시됩니다.
  아래 X / Y / Z = 커서 위치의 실좌표, Ctrl+1 · Ctrl+2 = 평면 · 단면 보기 켜기/끄기, F1 = 모든 단축키
  Z 옆 표시 = Z 출처: 「잎 표면」= 가장 상세한 메시에서 정밀 계산한 값, 「대략」= 정밀 값이 오기 전 화면용 값
  단면 머리의 「미리보기(거친) → 최종 계산 중…」/「✓ 최종(잎)」 = 지금 보이는 단면이 어느 단계인지
  상태줄 「축척」 칸 = 단면 화면을 1:20 / 1:40 … 으로 맞춤(화면 96 dpi 기준)
  보기 › 고대비 = 선·글자 진하게, 보기 › English = 영어 병기(기본 끔), 보기 › 단면선 굵기 1.5 / 2 / 3 px

■ 좌표계·높이 (1.1)
  - 단면 머리와 상태줄 오른쪽의 높이 배지: 「높이 EGM96 EPSG:5773 · 지정함」(확인됨), 「▲ 높이 타원체고 표기 · 확인」/
    「▲ 높이 기준 모름」(확인 필요), 「● 좌표계 없음」(없음). 누르면 「높이 기준 지정」. 경고는 리본 아래 한 줄 알림(「자세히」).
    EPSG 코드, 복합 EPSG, ENU, WKT1/WKT2 를 읽습니다.
  - 높이는 모델 좌표계 값 그대로입니다(지오이드 변환 안 함). EGM96·EGM2008·KVD1964(인천)·KNGeoid·타원체고를 알아봅니다.
  - iTwin 은 측량 높이(예: EGM96)를 그대로 넣어도 높이 축 이름을 「타원체고」로 붙입니다. 이때 노란 안내가 뜹니다.
    높이 배지(또는 「측정 › 높이 기준」)에서 실제 높이 기준(예: EGM96)을 고르면 이름표만 바뀌고 Z 값은 그대로입니다.
    지정값은 모델마다 저장되고, 같은 표기의 새 모델에는 마지막 지정값이 기본으로 적용됩니다.
    DXF 제목, GeoTIFF 수직 키, LAS, JSON 에도 지정한 높이 기준이 기록됩니다.
  - 여러 레이어가 합쳐진 3MX 는 좌표계·원점이 같은 레이어를 모두 읽습니다.

■ 참고
  - 단면선을 끄는 동안 입면 배경 영상은 화면용(거친) 메시로 빠르게 미리 보여 주고, 놓으면 가장 상세한(잎) 타일로 다시 그립니다.
    빨간 단면선(잘린 면)은 미리보기 때도 언제나 가장 상세한(잎) 메시로 자릅니다 — 끄는 중에도 위치·높이가 최종과 같습니다.
    단면 머리 정보 띠에 미리보기 → 최종이 표시됩니다. 내보내기는 항상 최종(잎) 결과입니다.
  - 평면 보기는 확대한 곳만 더 상세한 타일을 불러옵니다(GPU 예산 기본 768 MB).
  - 그래픽 드라이버가 OpenGL 2.0 을 지원하지 않으면 환경 변수 QT_OPENGL=software 로 실행하세요
    (동봉된 opengl32sw.dll 사용).
  - 설정은 레지스트리 HKCU\Software\ExcavSection\SectionViewer 에 저장됩니다. 최근 파일과 모델별 단면 목록·
    마지막 단면선·화면도 여기에 저장되므로 모델 폴더가 읽기 전용이어도 됩니다(모델 파일은 절대 바꾸지 않음).
  - 외부 구성요소 라이선스: licenses 폴더.
